## Gate ruling applied

@dev-pmallapp ruled at the implementation-review gate that a field whose
projection yields no information is **dropped entirely** rather than emitted as a
null husk. Four shapes were affected:

| Field | Before | After |
|---|---|---|
| biomarker, no reference range | `{in_range: null, direction: null}` | absent |
| unparseable account number | `{last_4: null}` | absent |
| unparseable timestamp | `null` | absent |
| non-numeric magnitude field | `{magnitude: "unknown"}` | absent |

Extended to containers, so dropping a leaf cannot leave `{a: {b: {}}}` behind.

## Design notes

`EgressConsent` is `{ granted: boolean }` and nothing more. A pure I/O-free
guard cannot honestly represent scope or expiry without implying a config layer
it must not have.

Because `classify()` lifts a payload to `SECRET` the instant a SECRET-shaped
value appears anywhere in it, `checkEgress` blocks **before** the projection code
runs. A secret cannot reach the redaction path at all.

A `PRIVATE` payload whose every field is unprojectable allows to cloud carrying
an empty object. Faithful to the matrix cell and it leaks nothing, but recorded
here because that cell can now yield an allow conveying no information.
