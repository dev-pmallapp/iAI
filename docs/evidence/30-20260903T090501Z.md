### Mutation 3 was a real gap, found and fixed before commit

On the first run, deleting the residual-brace check broke **no test**. The
reason is specific: an **unbalanced** brace never matches
`/\{([^{}]*)\}/`, so the unknown-placeholder scan sees nothing at all and only
the residual check catches it. Without a test,
`docs/evidence/{issue}-{ts.md` rendered to a filename containing a literal
brace — which is a file nobody would ever find again, and precisely the failure
Decision 7 exists to prevent.

Case 16 now covers four unbalanced forms and mutation 3 fails.

**This is the fourth task in a row where mutation-testing found something a
green suite did not.** The three kinds of survivor are now all documented:
a missing assertion (#27, #29), a fixture that cannot distinguish two keys
(#28), and a genuinely equivalent mutant (#29's `HARD_LIMIT_CHARS` guard).

## NEVER-26.9's invariants are structural, not checked afterwards

1. **An edit target always carries the requested sentinel**, because the target
   comes from `selectSentinelComment`, whose predicate *is* the sentinel match.
   There is no path that selects a comment by any other means. Case 23 confirms
   it against a corpus including a comment with no sentinel, one with a
   different sentinel, one indented and one buried below a preamble.
2. **Exactly one instruction is returned**, because the return type is a single
   `UpsertAction`. A create-and-edit pair is not representable. Mutations 4 and
   5 both break three cases, confirming the path is load-bearing.
