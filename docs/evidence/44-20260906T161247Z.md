The sentinel case is the sharpest. `SENTINEL_NAMESPACE_PREFIX` is the literal

describes the namespace and cites `sentinel.ts:53` for the prefix, never writing
it. This body follows that precedent. **The document that must describe a value
cannot name it** — the `NEVER-35.7` bind, and the reason `references/` exists.

The body also **names no domain at all**. It reads a label and loads whatever
that label resolves to, so a sixth domain is one binding file and no edit here.

## The hard-failure block had no canonical wording

There was **no existing template** for the block a Tier-1 verb emits when the
`domain:` label is absent. The closest prior art is
`docs/design/03-workflow.md:498-504` and its code reproduction at
`packages/core/src/guards/risk-mandate.ts:48-56`, both for an unrelated
rung-mandate failure. The shape is adopted from those:

```
- Story: #<n>

```

**This is the first Tier-1 instance and it sets the template for #42, #43 and
#45.** Recorded so the next three do not each invent one.

## A matcher rejected in review for contradicting a gate ruling

Case 12's *"absence of a default"* was first implemented as: **no domain id may
appear as a bare word anywhere in a Tier-1 body**, looped over
`KNOWN_DOMAIN_IDS` with word boundaries.

It passed. **It was wrong, and it would have blocked the next three tasks.**

- **Gate ruling G2 dropped `know` from the ban entirely** (Decision 4). #46

  whole-word hits across the twelve references — *"a whole-word rule does not
  save it"*.
- `references/domain-binding.md:13` states the doctrine **these skills
  implement** as *"The kernel does not know what `trade` or `health` means"* —
  **3 of the 5 banned ids in a single doctrine sentence.** A skill body quoting

It passed only because this particular body happens not to use those words. It
is the `NEVER-35.7` bind for a third time: **banning the words makes the owning
document unwritable.**

Replaced with the routing-form assertion — the machine-checkable half, already
ruled — plus a comment recording what a body can and cannot prove, and naming
**#293**'s execution harness as what would close the rest.

> **The lesson is not "that matcher was wrong".** It is that a test written to
> pin a *doctrine* reached past the doctrine's own ruling, and passed, because
> the corpus was one document large. A rule measured against one body is a rule
> written before its corpus.
