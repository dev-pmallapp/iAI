## A defect in the fixtures, found by mutation 3 and fixed before commit

**Mutation 3 originally did not break case 4.** The three `## iai-verdict`
fixtures were numbered 101, 102, 103 in ascending timestamp order. With the
`createdAt` comparison fully neutered, every instant compared equal and the id
tie-break supplied the correct winner — for entirely the wrong reason. Case 4
is the headline "newest by `createdAt` wins" case and it was proving nothing
about `createdAt` at all.

The fixtures now **anti-correlate**: ids descend 303, 302, 301 while timestamps
ascend. Mutation 3 now breaks cases 4 and 5 as well as 6 and 7, which is why it
is the widest-blast-radius mutation in the table.

**The general form of this defect is worth carrying forward.** A fixture whose
secondary key agrees with its primary key cannot distinguish which key the
implementation used. Any disambiguation test must make its fixtures disagree on
every axis it claims to test. The test file carries a comment recording this so
the numbering is not quietly restored.

## Design points verified

**The result is a normalised snapshot, not the input reference.** Every field is
read through a guarded reader before any is validated, so a hostile getter fires
once during validation and cannot fire again in the caller's hands. A test
counts getter invocations and asserts the count does not increase when the
result is touched. Extra input fields are dropped rather than passed through.

**`createdAt` is compared as a parsed instant, not lexically.**
`2026-09-02T07:18:21+00:00` and `2026-09-02T07:18:21Z` name the same instant but
sort differently as strings; a lexical compare picks the wrong winner. An
unparseable value sorts oldest so it can never win by accident, while remaining
reachable when it is the only candidate.

**The first-line rule is enforced by reusing #27's matcher.** `sentinelOf`
splits one line and calls `matchSentinelLine` rather than testing the body with
a second predicate, so the producer's linter and this query cannot disagree
about what carrying a sentinel means. Mutation 6 confirms the restriction is
load-bearing: matching any line instead of the first breaks case 4.
