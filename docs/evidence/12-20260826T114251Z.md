## A defect in the documented workflow, found while verifying

**`git commit` via an editor destroys a valid subject before the hook ever
runs.** git's comment character is `#`; every valid subject in this repo starts
with `#`. On the editor path git applies `cleanup=strip` after the editor and
before the hook, deleting the subject line as a comment:

```
### editor path: message typed as '#9: subject via editor' ###
Aborting commit due to empty commit message.

### same, with core.commentChar set to ';' ###
 1 file changed, 1 insertion(+)
7713518 #9: subject via editor
```

`-m` and `-F` use `cleanup=whitespace` and are unaffected — which is why this
has gone unnoticed. Every commit in this repository's history was written with
`-m` or `-F`.

This is not ISC-3's claim and is not "fixed" here. `scripts/install-git-hooks.ts`
now detects it and warns, because installing a commit-msg hook while the
subject convention is silently unusable on the editor path would be the wrong
kind of quiet:

```
install-git-hooks: WARNING core.commentChar is '#', which is also the first
install-git-hooks:         character of every valid subject in this repo.
install-git-hooks:         `git commit` via an editor will strip the subject
install-git-hooks:         and abort before the hook ever runs.
install-git-hooks:         Fix with: git config core.commentChar ';'
```

Warn, not set. Silently rewriting a user's git config is the class of side
effect `docs/design/09-security.md:361` exists to prevent.

## Purity, and why it is not fastidiousness

`packages/core/src/guards/commit-prefix.ts` performs no I/O, touches no
`process`, imports no `fs`. `docs/milestones/M1.md:95-97` commits S1.2 to a
harness that runs this suite with `fs`, `net` and `process` **stubbed to
throw** against exactly this directory. The argv read and the message-file read
live in `scripts/commit-msg.ts`.

`Action`, `Decision` and `decide` moved to `packages/core/src/decision.ts`.
Leaving them in `index.ts` meant the guard imported the package root while the
root re-exported the guard — a cycle that resolves under Bun today and is a bad
foundation for the four guards named at `ARCHITECTURE.md:88`.
