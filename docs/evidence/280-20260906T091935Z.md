## FINDING 2: the enforced contract set omits two constants case 15 names

Case 15 requires the checked constant set to be *"non-empty and ≥ 4 — at
minimum the sentinel namespace prefix, the commit-prefix regex, the 65536 hard
limit and the 60000 working budget"*.

The shipped set has **five** members and is comfortably ≥ 4, but the two budget
constants are **not among them**. It ships the sentinel prefix, the commit
regex, the exclusive-label array, the blob-SHA pattern and the sub-issue feature
header instead.

Measured, not assumed: **no reference document contains either budget number
today**, and `references/evidence-artifacts.md` — the document whose subject is
those budgets — handles them exactly as case 16 prescribes, naming
`packages/core/src/evidence/render.ts:40`, `:56` and `:59` without writing the
values out. So `NEVER-35.7` **holds in fact**. It is the *rule* that would not
catch a regression, not the corpus that has one.

The committed denominator assertion reads `>= 3`, not the `>= 4` the case
states.

**Disposition:** two lines in `contractDefs()`. Same owner and same decision as
finding 1.

## FINDING 3: `ci.yml`'s invocation is unchanged, and that is a deliberate deviation

Case 21 and requirement 2 of Decision 11 both say
`.github/workflows/ci.yml` *"carries the widened invocation"*. It does not. The
line is still:

```yaml
      - run: bun run skill-lint skills/
```

The widening was instead made **unconditional inside the script**: `main()`
resolves `CONTRACT_DIRS` relative to the repo root regardless of the CLI
argument, and a five-line comment above the CI step explains it.

This is arguably **stronger** than the plan's wording — a scope that cannot be
forgotten at a call site beats one that must be repeated at two — but it is a
deviation from a case, it is recorded rather than silently taken, and it has a
cost: **the second population is now invisible at the call site.** M10 is the
direct consequence.

`CONTRIBUTING.md` does carry the two-population description, as required.

`agents/` half of the widening is as vacuous today as `skills/` is. It is
correct to have wired it now, but no case exercises it and none can until an
agent file exists.
