because `Rung` is a full interface every restatement omits and `LabelDef` was
referenced in two documents and declared in none. The id union was opened

satisfies CLAIM-31.3, CLAIM-111.1's git-diff test and the purity constraint at
once. Validation happens at registration so resolution is a total lookup.

workspace package. A fixture inside `packages/core/test` would have satisfied
every assertion while proving nothing.

**#272** made both promises enforceable: `no-io-in-pure-modules` widened to
`core/src/binding` with claim attribution, and `no-domain-pack-import` authored
from nothing.

## Four findings that changed the code

1. **`domainLabelFor` was not total.** #272's reflective sweep found 2 of the
   barrel's 7 exported functions threw — on a `Symbol` and on a hostile
   `toString` — because template interpolation throws on a *value* rather than
   misbehaving. Every other function routed reads through `own()`.
2. **A range-based exemption is a hole.** #34's case 14 exempted a *line range*
   for the id union, and `export const DEFAULT_DOMAIN: KnownDomainId = "dev"`
   inserted into the gap survived all 755 tests and lint. Now shape-based with a
   pinned count.
3. **A static import runs before every guard a test file installs.** #272's
   surviving mutant was obfuscated I/O at module-evaluation time, invisible to
   both the lint rule and the harness. Closed with `await import()` inside the
   test.
4. **A guard shadowed by another guard**, three times in #33 — including a
   "distinctness" assertion that was not distinct, because two messages
   differing only in the value they quote are one message.
