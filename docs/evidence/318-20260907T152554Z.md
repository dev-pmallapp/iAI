## Two findings from writing it

### 1. My first detection regex reproduced a false positive this repository already documents

Case 12's first draft used `/\b(exec|execSync|spawn|spawnSync|execFile…)\s*\(/`
and matched **`RegExp.prototype.exec(`** — reporting
`packages/core/src/gh/sub-issues.ts`, which is *provably pure* by three
independent mechanisms, as a process launcher.

`scripts/lint.ts:255-258` names that exact false positive and **accepts it
there**:

> *"RegExp.prototype.exec called with a template literal as its first argument
> will also match here; accepted as a deliberately strict, low-frequency false
> positive rather than special-casing the regex-vs-child_process ambiguity."*

**That trade is correct for a ban and wrong here.** For a ban, a false positive
is noise and someone fixes it. For an assertion of the form `toEqual([])` over
the whole tree, a false positive is **red against correct code** — and the
cheapest fix under time pressure is an exemption for `sub-issues.ts`, which
would have been the silent direction at its sixth recorded occurrence.

> **The same trade-off has opposite answers depending on whether the rule bans
> or asserts.** Detecting the capability — the import — has no ambiguity to
> trade away.

### 2. The carve-out I did not write

Test files legitimately spawn `tsc`, `bun` and `git`: the type-test compilers,
the two child-gated purity suites, and the real-git fixture in
`commit-prefix.test.ts`. Six files, all correct.

The obvious shape is `if (rel.includes("/test/")) continue;`. **That is a
derived, uncounted carve-out** — precisely what #307 finished removing from this
repository hours earlier, and what `docs/evidence/46-*.md` records as the
dangerous direction because *an over-broad exemption never announces itself*.

Instead both halves are named, both asserted non-empty, and asserted to **sum to
the whole**:

- if production source ever empties, the ban is vacuous → fails
- if the other half ever empties, the carve-out is hiding something → fails
- if a file falls between the two predicates → fails

**And the ban carries its own `> 0` half**: *"exactly one production module
launches, and it is the port."* A port that launched nothing would satisfy the
ban perfectly and be useless — the shape of finding 10, where an assertion is
trivially true of any input.
