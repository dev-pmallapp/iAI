## Order is the rule; membership alone is not

`references/design-format.md:52` defines conformance as *"preserves relative
order; it does not pad"* — an **ordering** property, never a membership one.
This rule makes that checkable, and the distinction is load-bearing: a
presence-only check passes a Design whose `Decisions` precede its `Problem`.
Mutations M2 and M3 exist to prove the ordering half is doing work the presence
half is not, and both were killed.

Extra sections are permitted precisely because the contract is about order.
`docs/design/stories/194.md`'s `## Mapping` and `docs/design/stories/15.md`'s
`## Addendum` — the only two additions in the entire corpus — both pass, which
is case 16.

## The one outlier warns rather than fails, and that is the ruling

`docs/design/stories/9.md` opens with YAML carrying **seven** keys where
`references/design-format.md:31` specifies four, and its values went stale the
day the Story shipped (`phase: scoping`, `progress: 0/9` on completed work). The
other eight open with an H1 title and a bolded metadata block.

Gate ruling **G1b** was that the rule describes the 8-of-9 convention and the
outlier is **recorded rather than failed**. A warning is the only shape that
does both:

- an **error** would force either rewriting a shipped historical document to
  satisfy a rule written years after it, or a permanent exemption that hides the
  outlier — the thing an exemption always does;
- **silence** would mean the outlier stops being visible the moment it stops
  being novel.

A warning prints on every run and exits 0. `claim-lint`'s `main()` exits
non-zero only on `severity === "error"`, so the chain stays green with the
warning present — asserted directly, so that nobody can promote the ruling into
a hard failure without a test going red. **Mutation M6 does exactly that
promotion and kills four cases.**

## Two plan amendments, recorded rather than silently applied

Both were found by **implementing** the plan, not by reviewing it.

**1. Cases 2, 8, 9 and 16 move from `bun run skill-lint` to `bun run claim-lint`.**

The plan assigned a **Design-document** rule to the **skill** linter.
`skill-lint` scans `skills/`, `references/` and `agents/`; `docs/design/stories/`
is in none of them and is squarely inside `claim-lint`'s `SCOPE_DIRS`. The
sibling precedent is decisive: `testplan-corpus` — the same shape of rule for
test plans — lives in `claim-lint`.

> **Test plans and Designs are siblings, and their linters must be too.**

Had the plan been followed literally, the rule would have been added to a linter
that cannot see the files it governs — which is precisely finding 27 of S2.1,
where `skill-lint` was named as the tool for a claim over `references/` and
could not see a single file it was asked to scan. **Second occurrence of that
class.**

**2. Case 2's denominator becomes a run-time count instead of the literal
"9 of 9".**

The literal was **stale before it was committed**: `docs/design/stories/41.md`
is itself a Design, so the corpus was **10** the moment the plan landed. Same
defect class as finding 3 — a counted denominator drifts, a read one cannot. The
case now reads the count at run time and asserts it before asserting the result,
and the test asserts `>= 10` rather than a fixed number, so a new Story cannot
turn it red.

## Corpus

Per #289, stated per artifact and not only per case. **Every negative fixture in
`packages/core/test/design-spine.test.ts` is a real shipped Design with exactly
one perturbation** — `perturb()` reads a document off disk and changes one
string. There is no invented Design text anywhere in the suite.

That is not stylistic. The rule exists because the seeded form of `CLAIM-41.3`
would have rejected 9 of 9 real Designs — a rule written before anyone looked at
the corpus it governs, the third instance of that defect after #287 and #289.
Authoring invented fixtures here would have reproduced the defect inside the fix
for it.

Two positive cases run the unmodified roster. The "extra sections pass" case is
proved against the two real documents that carry extras, rather than against a
document constructed to agree with the predicate.
