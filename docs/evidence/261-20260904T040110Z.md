## Mutation 7 is a hang, and a hang is worse than a throw

Removing the `Array.isArray` guard from `sentinelNamesArePrefixFree` does not
produce a failing assertion. It produces a run that **never finishes** — killed
at the 60-second cap, exit 124. Handed the corpus's 200,000-character string,
`for (const a of names)` iterates 200,000 characters and the nested loop runs
4x10^10 comparisons.

This is the defect the implementation commit records, re-confirmed here against
the committed tree. It is worth stating plainly because the corpus was built to
catch throws: **`expect(fn).not.toThrow()` cannot catch a function that never
returns**, and `CONTRIBUTING.md`'s 50 ms guard budget exists for exactly this
class of failure. Case 22 catches it only because a hung test is a red CI job.
Nothing in this repository yet asserts a *time bound* on a pure predicate.

could be deleted with nothing failing.

fixture, and not an equivalent mutant, but **a guard shadowed by another guard**
so that no reflective input can reach it.
