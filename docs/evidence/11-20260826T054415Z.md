## Not verified here

`lint` and `skill-lint` are still placeholders (#187, #13). They are required
contexts that currently cannot fail, so ISC-4, ISC-5 and ISC-9 remain unmet.
The contexts exist now so the contract is enforced from the start, but a green
`lint` on this PR means only that the placeholder ran.

The both-host install smoke test is not implemented. `packages/installer` has
no `cli.ts`, and `docs/design/9-isa.md` puts installer CLI behaviour out of
scope for this story. `smoke-install` is deliberately non-required and says so
in its own output. `PLAN.md`'s mitigation "CI installs and smoke-tests both
hosts on every PR from M1" is therefore **aspirational as of this story** and
is genuinely satisfied only when the installer CLI ships in M8.
