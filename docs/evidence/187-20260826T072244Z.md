## Scope asymmetry, carried forward not resolved

`docs/design/9-isa.md` Constraints bans `process.cwd()` in `packages/core` and
`packages/adapter-opencode`, and says nothing about `packages/adapter-claude`.
The rule is implemented exactly as written, asymmetry included, and there is a
test pinning it. Either the ISA means it and the reason is unrecorded, or it is
an omission. This is a design-claim discrepancy, which is #14's job under
ISC-6, so it is recorded here rather than silently "fixed".

## Known limitations

`no-exec-template` matches any `exec(` or `execSync(` whose first argument is a
template literal, which includes `RegExp.prototype.exec`. Accepted as a strict,
low-frequency false positive rather than guessing at the receiver.

The comment masker tracks the three string forms but not regex literals, so a
regex containing `/*` or `//` could be misread as a comment opener. No file in
`packages/**` contains one today. Both limitations are commented at their
definitions rather than left for a reader to discover.
