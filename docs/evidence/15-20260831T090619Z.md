## Defects found during the Story, and how

Three defects were invisible to the tests written alongside them and were caught
only by probing the code directly. Recorded here because the pattern matters more
than the individual bugs.

| Defect | Consequence | Found by |
|---|---|---|
| `checkRiskMandate` rejected the `rung:` label form | would have refused **every** legitimate auto run | direct probe; not one of 39 tests used the label form |
| `iai-core` exports map named only `dist` | CI `test` job could not resolve the package | CI red while local green |
| `mock.module` leaked process-wide | broke an unrelated test file | CI red while local green |

Two of the three were green locally and red only in CI. The third passed its own
suite completely. In each case the test fed the code a value in the shape the
implementation had chosen, rather than the shape a real caller would supply.
